# Product Context

## What This Project Does

This is a comprehensive personal portfolio website built on Laravel that serves as a digital hub for showcasing professional accomplishments and technical content. The platform provides multiple content types and interactive features:

### Core Functionality
- **Blog System**: Publish and manage technical blog posts with commenting
- **News Section**: Display announcements and updates 
- **Photo Gallery**: Manage and showcase photo collections
- **Resume Section**: Professional resume presentation
- **Multimedia Content**: Music and video sections

### Interactive Features
- **Real-time Chat**: Private and group messaging system
- **Comment Moderation**: Async comment processing via RabbitMQ queue
- **Captcha Protection**: Form validation to prevent spam
- **Bilingual Support**: Russian and English language availability

### Technical Features
- **Content Delivery**: REST API and GraphQL API endpoints
- **Documentation**: Swagger/OpenAPI documentation
- **Authentication**: Laravel Sanctum for API access control

## Problem Domain

The project addresses the need for a unified digital presence that combines:
1. Professional portfolio showcasing skills and experience
2. Technical blog for knowledge sharing
3. Media sharing for visual content
4. Modern web application with responsive design

This eliminates the need for multiple separate platforms and provides a cohesive user experience.
