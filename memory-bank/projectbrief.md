# Project Brief

This is a personal portfolio/site built on Laravel that provides:

- Blog functionality with posts and comments
- News section for announcements
- Photo gallery management
- Real-time chat system (private and group chats)
- Bilingual support (Russian/English)
- GitHub repository: a-potap/laravel

The site showcases my professional resume, technical blog posts, news updates, photo collections, music, and video content all in one place.

## Key Features

- Personal portfolio site with modern web technologies
- Content management for blog posts, news, and photos
- Interactive chat system for community engagement
- Comment moderation system with RabbitMQ queue processing
- Responsive design with multilingual support
- REST and GraphQL APIs for content delivery
